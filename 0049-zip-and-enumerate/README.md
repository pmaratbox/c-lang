# 0049 — Zip & Enumerate

Pair the letters `a, b, c` with the numbers `1, 2, 3` position by position, formatting each pair as `key=value` and printing `a=1 b=2 c=3`. C has no zip or higher-order iteration; a single index loop reads from both parallel arrays. The arrays must be kept the same length by hand.

## Run

    make && ./zip
