# 0090 — Binary Search Tree

Insert `5, 3, 8, 1, 4` into a binary search tree and print an in-order traversal (which yields the values in sorted order): `1 3 4 5 8`. Nodes are heap-allocated with `malloc`; `insert` links smaller values left, larger right, and the in-order traversal prints them sorted.

## Run

    make && ./bst
