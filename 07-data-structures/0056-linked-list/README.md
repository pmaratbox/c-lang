# 0056 — Linked List

Build a singly-linked list holding `1`, `2`, and `3`, then traverse it from head to tail and print `1 -> 2 -> 3`. A `struct Node` holds an `int` and a `struct Node *`; nodes are heap-allocated with `malloc`. There is no automatic cleanup, so the list is explicitly `free`d after traversal.

## Run

    make && ./linkedlist
