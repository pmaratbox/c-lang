# 0064 — Matrix Transpose

Transpose the 2x3 matrix `[[1, 2, 3], [4, 5, 6]]` (swap rows and columns) and print the resulting 3x2 matrix, one row per line: `1 4`, `2 5`, `3 6`. Printing column-major (`matrix[i][j]` with `j` outermost) emits the transpose directly, without building a second array.

## Run

    make && ./transpose
