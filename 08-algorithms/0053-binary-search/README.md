# 0053 — Binary Search

Binary-search the sorted array `1, 3, 5, 7, 9` for `7` and print the index where it is found: `found 7 at index 3`. The array length is recovered with `sizeof(nums) / sizeof(nums[0])`. The stdlib `bsearch` performs the same search behind a comparator callback.

## Run

    make && ./binsearch
