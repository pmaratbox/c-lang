# 0037 — Operator Overloading

Define how `+` (or an `add` method) combines two points, then add `(1, 2)` and `(3, 4)` and print `(4, 6)`. C has no operator overloading; operators apply only to built-in types. A plain `add` function that takes and returns `struct Point` by value is the equivalent.

## Run

    make && ./operators
