# 0066 — Multiple Assignment & Destructuring

Swap two variables (`a = 1`, `b = 2`) with a single multiple-assignment, then unpack the pair `(3, 4)` into two variables — printing `2 1` then `3 4`. C has no destructuring or multiple assignment: swapping needs a temporary, and a pair (here an array) is unpacked element by element.

## Run

    make && ./destructuring
