# 0048 — Maps: Iterate & Transform

Build a map from letters to numbers (`a`->1, `b`->2, `c`->3), sum all its values, and print `sum: 6`. C has no map type; an array of key/value `struct`s is the manual stand-in, iterated by index to sum the values. A real associative map needs a hash-table library.

## Run

    make && ./maps
