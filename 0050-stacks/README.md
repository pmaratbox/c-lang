# 0050 — Stacks

Push `1`, `2`, and `3` onto a stack, then pop them all off and print them in last-in-first-out order: `3 2 1`. An array plus a `top` index is a manual stack: `stack[top++]` pushes and `stack[--top]` pops. There is no bounds checking, so the capacity must be sized to fit.

## Run

    make && ./stacks
