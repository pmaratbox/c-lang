# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. The conditional operator `cond ? a : b` is C's only ternary — it evaluates exactly one of the two operands and yields its value. Its two result operands are converted to a common type (here both are string literals).

## Run

    make && ./ternary
