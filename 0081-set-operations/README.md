# 0081 — Set Operations

Compute the union and intersection of the sets `{1, 2, 3}` and `{2, 3, 4}`, printing the union `1 2 3 4` and the common elements `2 3` (each in ascending order). With no set type, scanning the candidate values `1..4` in order and testing membership gives union (in either) and intersection (in both), already sorted.

## Run

    make && ./setops
